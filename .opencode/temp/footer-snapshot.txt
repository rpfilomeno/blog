    uid=4_18 StaticText "Applying to jobs is repetitive. Name, email, phone, location, company, LinkedIn, GitHub, upload CV, answer three yes/no questions, solve a CAPTCHA, submit. Every form is slightly different, but the data is the same. I wanted to see if I could automate the whole thing using CloakBrowser MCP — a stealth Chromium wrapper that runs as a Model Context Protocol server."
    uid=4_19 StaticText "The short version: it worked, but the CAPTCHA was the hard part."
    uid=4_20 heading "Why CloakBrowser" level="2"
    uid=4_21 StaticText "Regular Playwright or Puppeteer gets detected. Sites check for headless browser signatures — missing WebGL vendors, navigator.webdriver set to true, inconsistent viewport sizes. CloakBrowser patches these. It spoofes fingerprints, removes automation indicators, and runs Chromium with stealth mode enabled."
    uid=4_22 StaticText "The MCP part means I can control the browser from any tool that speaks the protocol. In my case, opencode — an AI coding assistant — connects to CloakBrowser as a remote server on "

    uid=4_23 StaticText "`"
    uid=4_25 StaticText ". I describe what I want in natural language, the agent picks the right tool calls, and the browser executes them."

    uid=4_164 heading "What I learned" level="2"
    uid=4_165 StaticText "hCaptcha is the real gate."
    uid=4_166 StaticText " The form was straightforward — ten text fields, four dropdowns, three radio buttons. The CAPTCHA existed, but it didn’t trigger a challenge. It just sat there as an iframe, blocking pointer events. If it had actually challenged me with image selection, I would have been stuck. CloakBrowser handles fingerprint detection, not CAPTCHA solving."
    uid=4_167 StaticText "JS evaluate is the escape hatch."
    uid=4_168 StaticText " Every time a Playwright tool failed because of an overlay or iframe, "
    uid=4_23 StaticText "`"
    uid=4_169 StaticText "evaluate"
    uid=4_23 StaticText "`"
    uid=4_170 StaticText " with raw DOM manipulation worked. It runs in the page context, bypasses actionability checks, and fires native events. It should be the first option when clicking through an iframe-blocked element."
    uid=4_171 StaticText "Persistent profiles matter."
    uid=4_172 StaticText " Without "
    uid=4_23 StaticText "`"
    uid=4_173 StaticText "CLOAK_PLAYWRIGHT_MCP_PERSISTENT_DIR"
    uid=4_23 StaticText "`"
    uid=4_174 StaticText ", every session starts clean. You lose cookies, logins, and any CAPTCHA tokens you already solved. The profile directory is the difference between a tool you use once and a tool you use daily."
    uid=4_175 StaticText "Snapshots are cheap, stale refs are expensive."
    uid=4_176 StaticText " The element refs from a snapshot are valid until the page changes. If you navigate, scroll, or wait long enough for a lazy render to kick in, the old refs are dead. Snapshot before every action, not once at the start."
